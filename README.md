# HomeLabV1

A multi-node ecosystem featuring a Raspberry Pi 5 and an HP EliteDesk running proxmox.

- **node-lab:** EliteDesk - Proxmox / Sandbox. (16GB), 256 NVME SSD.
- **Network:** 8-Port Managed Switch
